## 翻訳帳プレビュー

§4.1 で「将来 `docs/CHOREOGRAPHY.md` として公開・運用される」とされている、音響事象→妖怪の振付の対応表のドラフト。**このファイル自体は `docs/CHOREOGRAPHY.md` ではない** — 正式な発行は Step 4(§5)の release criteria。

| 音響事象 | 妖怪の振付 | 状態 |
|---|---|---|
| 音量の高まり | 行列全体が音量に応じて跳ねる — 固定サイン波 × 音量の疑似ビート | 近似・実装済み |
| 提灯の明滅 | アタックは速く、リリースは遅い非対称スムージングで灯りが揺れる | 実装済み |
| 強打(音量閾値) | 唐傘が開く / 天狗が hit フレームへ切り替わる | 音量閾値の近似 |
| 時刻 2:00 / 月タップ | 丑三つ時へ — 空が紅に染まり、一つ目小僧が最後尾に加わる | 実装済み |
| アタック・無音・曲の歩み | 正式 SDK で利用できると確認できた Music Understanding の結果、または後から追加する限定的な演出用解析で、木魚・天狗・唐傘の反応精度を上げる | 未着手・入力方式未確定 |
| 聴取史(residency) | 住み着いた妖怪や提灯の色が聴取史を映すようになる | 器のみ・未接続 |
| アートワークの音量 | 人魂がゆらぎ、明滅する(下記・新規提案) | 新規提案 |
| 強いパーカッションの連打 | がしゃどくろの骨が小刻みに震える(下記・新規提案) | 新規提案 |

現在地(正直に): 音響側の語彙はまだ `averagePower` 1語のみ。アタック・無音・pace を表す入力は未実装で、Music Understanding の正式版 SDK で使える結果を確かめるか、必要なものだけを後から限定的な演出用解析として足す。

**Listening Profile との境界**: Step 3「狐火の調律」は、ヘッドホンで音をどう聴くかをユーザーが選ぶための再生音処理である。ここにある翻訳帳は、妖怪が曲をどう読むかを決める演出用入力である。前者を実装しただけで後者が完成したことにはせず、同じ巨大な解析経路へ結びつけることも前提にしない。

## スプライト解像度の方針 — 全妖怪をSNES級へ

**方針(2026-07-10 決定)**: がしゃどくろだけでなく、**全ての妖怪(行列8体・一つ目小僧・ぬりかべ)をスーパーファミコン級の解像度のドット絵へ刷新する。** 8bitの記号性より、骨の面・衣の襞・提灯の照り返しまで描き込める解像度で、一体あたりの深度(§4.1)を絵柄でも引き上げる。

- **時期**: アセット制作は実装が進んでから。挙動(Step 4「夜行絵巻 2.0」で、演出用入力と反応の種類・フレーム数を確定する)が固まる前に描き直すと二度手間になるため、それまでは現行の8bit体を維持する。Step 3 の Listening Profile は再生音の聴き方を選ぶ機能であり、スプライト制作の確定条件にはしない。
- **先行第一号**: がしゃどくろ(下記・コンセプト)。リファレンス画像 → 面積平均ダウンサンプル → k-means限定パレット量子化という制作パイプラインはここで確立済みで、残りの妖怪にも流用できる。
- **変わらないもの**: ピクセルアートはにじませない(§8)。1文字=1ドットの行文字列+パレット形式(`PixelSprites.swift`)も維持し、解像度だけを引き上げる。

## 新規提案(まだ憲章に無いもの)

どちらも翻訳帳(§4.1)と同じ規律 — 演出のための演出ではなく、必ず音響事象と結びつくこと — で考えた案。

### 人魂 — アートワークの視線

実装済みの円形ウェーブフォームは「音量」を伝えるだけで、民話の語彙ではない。狐火(kitsunebi)と同じ「浮遊する霊」の語彙をアートワークにも持ち込み、提灯と同じ音量明滅の仕組みで動かす案。新規トークンは足さず、既存の狐火/提灯/月白の色を再利用する。

![hitodama](design/hitodama-proposal.png)

### がしゃどくろ — 丑三つ時の奥に、ただ一体

名の由来は骨が鳴る「がしゃがしゃ」という音 — 強いパーカッションの連打に骨が震える、翻訳帳的な必然がある新規キャラクター案。ただし §4.1 は頭数ではなく一体あたりの深度に投資する方針であり、§6 は妖怪の頭数を増やすこと自体を目的にしないと定めている。したがって**行列には加えない**。丑三つ時にだけ、夜空の奥にただ一体 — 月光に沈む頭蓋、眼窩の紅、肋骨の檻、行列の上へ差しかかる指骨 — が気配として佇む。行列の仲間ではなく、丑三つ時という時刻そのものの一部として。

ドット絵は歌川国芳「相馬の古内裏」の骸骨を下敷きに、**スーパーファミコン級の解像度(125×105ドット・限定11色)**で起こした2フレーム構成 — 全妖怪をSNES級へ刷新する方針(下記)の先行第一号。idle と rattle(下顎・指骨・肋骨だけを1ドット震わせ、頭蓋は動かさない)を持ち、連打の合図で切り替わる。インタラクティブ版ではパネルに触れると骨が鳴る。
