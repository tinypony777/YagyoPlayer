# 妖怪 × 浮世絵 × モダンレトロ × 大正ロマン — 一枚摺デザインレビュー追補

**状態:** 実装済み
**作成日:** 2026-07-16
**対象:** PR #28「妖怪×浮世絵×モダンレトロへ全面刷新」のデザインレビューと修正
**上位仕様:** `2026-07-15-yokai-ukiyoe-modern-retro-redesign.md`(構図・色・部品の正本。本書は上書きせず仕上げのみ扱う)

## 1. レビューの結論

一枚摺の番付という骨格 — 生成り紙、限定色、切り角の版木枠、縦外題、木版妖怪9体、丑三つ時の局所暮色 — は成立している。弱いのは**仕上げの語り口**で、特に大正ロマンの「和洋折衷」が中途半端だった。明治大正のラベルは日本語が主、ローマ字は飾りである。現状は逆で、見出しのローマ字飾り(YŌKAI REGISTER 等)の下に、説明文・検索・メニュー・アラートが素の英語UI文のまま残り、「意匠」ではなく「未翻訳」に見えていた。

## 2. 修正項目

### 2.1 和洋折衷の文言統一(大正ロマン)

英字はオーバーライン(YŌKAI REGISTER / BOUND VOLUMES / ANALYSIS LEDGER / FIXED EQ AUDITION)と YAGYO PLAYER 題字、技術語(Music Understanding、Fixed EQ、LUFS計測名、音源形式名)にのみ残し、利用者へ語りかける文はすべて日本語へ改めた。

- 見出し説明: 「この端末に納めた音源の番付」「曲を好きな順に綴じる帳」「端末内で解析 · 読み取りのみ」「iOS 27 · 同じ曲での聴き比べ」
- 検索: 「曲名・作者・ファイル・覚え書きで探す」
- 文脈メニュー: 札を直す / 巻物へ綴じる / 行列から外す / 巻物を通しで聴く / 名を改める / 巻物を捨てる / 一つ上へ / 一つ下へ / 綴じから外す
- アラートと編集シート: 取込に失敗しました / 巻物の名 / 作る / 改める / やめる / 保存 / 覚え書き / 納めた写し
- 曲数表示: `2 tracks` → 「全2曲」

### 2.2 短冊を短冊にする(浮世絵・番付)

`StepProgressBar` の目盛は横長ブロック(約17×7pt)で、欄外注の「短冊」と矛盾していた。幅を9ptへ固定し余りを目盛間へ配って、縦長の紙片(9×15 / 拍頭9×21pt)へ改めた。書き入れ前の短冊は濁った鼠(`paperMuted`)をやめ白紙(`paperRaised`+細罫)にした。朱=再生済み、柿=現在位置、拍頭が背高という意味は不変。scrub操作面44ptと`fraction`写像も維持(spacingを引数化)。

### 2.3 操作を札として立てる(モダンレトロ)

- 行列の絞り込みメニュー2つ(巻物範囲・並び順)は裸の朱文字でコントロールに見えなかった。`FilterPlaque`(持ち上がった紙+藍鼠の単罫、44pt)へ載せた。
- 前曲/次曲の丸紋に内側の紙色罫を足し、再生ボタン・ミニ灯り・引札と同じ「罫と丸紋」の家族にした。
- YAGYO PLAYER 題字札へ内側の飾り罫を足し、縦外題柱と同じ二重罫の文法にした。

### 2.4 欄外注の統一(一枚摺)

`RetroMarginalNote` を共通部品化し、「注　…」の語り口を三面で共有する。

- 夜行: 「注　音の足跡は直近の響き・短冊は曲の位置」(既存文言を部品へ移設)
- 行列: 開発者向け英語パネル(Built for iOS 26+ … MusicKit)を廃し、「注　音源の写しはこのアプリの内にだけ納められる · iOS 26以上」の欄外注へ
- 巻物: 上位仕様§7.3の「空白を放置しない」を実装 — 「注　行列の曲は長押しで巻物へ綴じられる」

### 2.5 VoiceOver の日本語化

前の曲 / 次の曲(ラベル欠落でSF Symbolの英語既定読みだった)、再生 / 一時停止、音源を納める、巻物を作る。既存の日本語ラベル(ミニ灯り、音量、再生位置、月に触れる)と揃えた。

## 3. 変えないもの

- 木版妖怪9体の正本、resident順、歩行・静音・強反応matrix、Reduce Motion契約
- 横長「音の足跡」の状態契約(止/—/静/響/烈)と描画
- Tab順、URL routing、データモデル、再生・DSP・解析
- 色Palette、`WoodblockFrameShape`、panel文法(新しい色・依存は追加しない)
